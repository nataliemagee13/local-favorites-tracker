# Local Favorites Tracker

A small web app for saving favorite local places, including their category, rating, go-to item, and notes. Favorites persist between visits with browser `localStorage`.

## Built With

- HTML
- CSS
- JavaScript

## Live Site

https://nataliemagee13.github.io/local-favorites-tracker/

## Notes

Favorites are stored locally in the browser, so each browser and site address has its own saved list. The live site starts with an empty list until favorites are added there.
